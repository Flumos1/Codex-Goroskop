# Codex Goroskop: project brief

## Purpose

Build a serious astrology platform that combines research, knowledge base, natal chart analysis, interpretive methodology, and a horoscope generator.

The project is not positioned as entertainment. It should offer psychological, spiritual, esoteric, and research-based help through symbolic interpretation of birth data and planetary cycles.

## Audience

- General users without astrology background.
- Advanced users who expect deeper explanations, source-aware interpretation, and transparent methodology.

## Style

- Research-oriented.
- Spiritual and psychological.
- Calm, premium, trustworthy.
- No cheap entertainment tone.

## Source Languages

- Russian.
- English.
- Ukrainian.

## Source Intake

Put new books and documents here first:

`sources/books/inbox/`

After review, selected and summarized materials can be moved or mirrored into:

`sources/books/processed/`

For each source we should eventually capture:

- Title.
- Author.
- Language.
- Tradition or school.
- Source type.
- Key concepts.
- Useful interpretation rules.
- Contradictions or caveats.
- Reliability notes.

## Core Workstreams

- `sources/`: raw books, links, videos, and external materials.
- `research/`: notes, summaries, comparisons, and conclusions.
- `knowledge-base/`: structured astrology concepts.
- `methodology/`: our interpretation rules and ethical frame.
- `generator/`: horoscope generation logic.
- `site/`: web application.
- `docs/`: planning and project documentation.
