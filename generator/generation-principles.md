# Generation Principles

## Rule

Generate reports from structured interpretation data, not from free association.

## Interpretation Pipeline

1. Calculate chart data.
2. Identify relevant factors.
3. Map factors to knowledge-base meanings.
4. Combine meanings through synthesis rules.
5. Detect repeated themes.
6. Apply safety boundaries.
7. Render simple and/or advanced report.

## Psychological Aspect Pipeline

For psychologically oriented natal readings:

1. Treat each aspect as a possible inner expectation or belief.
2. Describe the pattern as a tendency in perception, not a fixed event.
3. If parents or childhood are involved, use symbolic and cautious wording.
4. Add a constructive channel for the same energy.
5. In advanced mode, show the chart factors and method family.

## Report Requirements

Every report should include:

- Main themes.
- Strengths.
- Tensions or growth tasks.
- Practical reflection.
- Clear uncertainty language.

Advanced reports should additionally include:

- Technical chart factors.
- System separation: Western and Vedic.
- Confidence labels.
- Method notes.

## Source-Aware Generation

When a rule comes from a source family, record that family in internal metadata:

- Classical Western.
- Psychological/archetypal.
- Modern practical.
- Vedic/Jyotish.
- Special-topic caution.

The user-facing report may show this in advanced mode.
