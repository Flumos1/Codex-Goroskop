## Simple Explanation

The Vedic branch reads the chart through a separate symbolic and calculation system.

The first anchor is Lagna, the rising point, which becomes the main reference for houses. From there, planets, signs, houses, divisional charts, lunar mansions, and timing periods are considered as connected layers.

This report should be read as a structured map of tendencies and timing themes, not as a fixed sentence about fate.

Reflection: Which life area are you asking about: self, relationships, work, resources, family, spiritual practice, or timing?

## Advanced Explanation

This Jyotish framework uses grahas, rashis, bhavas, and vargas as core pillars. Unless otherwise stated, houses are counted from Lagna and the zodiac mode is sidereal / nirayana.

Vedic interpretation must state its reference point and chart layer. A house read from Lagna is not the same as a house read from Chandra Lagna or another special Lagna.

Dashas and transits are treated as timing themes. The public product should not generate death prediction, medical certainty, or guaranteed events.

The constructive use of Jyotish in this project is self-understanding, timing awareness, and reflective planning with clear uncertainty language.
