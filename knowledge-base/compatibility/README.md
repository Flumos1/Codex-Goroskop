# Compatibility Knowledge Base

Compatibility is a dedicated product domain.

It is not one tradition by itself. It may use Western astrology, personology, Jyotish, Chinese/Eastern systems, and other source-backed methods, but each claim must mark its source system.

## Initial Scope

- Romantic compatibility.
- Marriage / long-term partnership.
- Parent-child compatibility.
- Mother-child and father-child dynamics.
- Friendship.
- Work and business cooperation.
- Family and social relationship patterns.

## Working Files

- `relationship-types.md`: supported relationship contexts and output axes.
- `safety-boundaries.md`: language rules for non-deterministic compatibility output.
- Goldschneider source notes in `research/source-notes/`.

## Safety Standard

Do not produce final verdicts such as:

- perfect match;
- doomed relationship;
- must marry;
- must separate;
- bad parent;
- bad child.

Use multi-axis interpretation:

- ease;
- friction;
- emotional needs;
- communication;
- practical cooperation;
- growth;
- boundaries.
