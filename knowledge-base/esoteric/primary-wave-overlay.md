# Primary Wave And Overlay Architecture

## Purpose

The project uses a two-layer model for some reports:

- primary wave: the main source lens requested by the user;
- overlay: additional source-backed systems that refine, contrast, or contextualize the primary reading.

For the first version, Goldschneider's `Тайный язык дня рождения` is the primary-wave source for birthday-personology reports.

## Source-Only Mode

Source-only mode answers from one declared source.

For Goldschneider birthday-personology:

- input can be a birth date without birth time;
- output should state that it is using the birthday-personology source;
- output should not import natal chart, Jyotish, Chinese, Kabbalah, or compatibility claims unless the user asks for overlays.

## Stereo Mode

Stereo mode combines:

- the primary wave;
- one or more overlays.

The report must label each layer. If layers differ, the output should frame the difference as separate symbolic lenses.

## Overlay Examples

- Compatibility overlay: relationship type, interaction axes, non-verdict language.
- Western natal overlay: planets, signs, houses, aspects.
- Kabbalistic/esoteric overlay: only when source-backed.
- Jyotish overlay: only with explicit sidereal/Jyotish calculation context.
- Chinese / Eastern overlay: only as its own branch.
- Applied symbolic overlay: name, color, sound, talisman, calendar, plant, or mineral symbolism.

## Safety

The primary wave must not become a totalizing identity claim.

Use:

- tendencies;
- symbolic emphasis;
- reflection prompts;
- contrast between source lenses.

Avoid:

- "this is who they are";
- "this relationship is destined";
- "this person will definitely...";
- medical, legal, financial, or family directives.
