# Rectification Knowledge Base

Rectification is a specialized technical domain for working with uncertain birth time.

## Current Source Families

- Agafonov rectification books and Pushkin rectification case.

## Product Role

Rectification should support:

- birth-time uncertainty handling;
- event-based chart correction;
- explicit confidence levels;
- clear separation between calculated data and inferred birth-time hypotheses.

## Safety And Method Limits

Do not present rectified time as guaranteed.

Every rectification output should include:

- original known birth data;
- events used;
- methods used;
- confidence level;
- alternative candidate times when relevant.
