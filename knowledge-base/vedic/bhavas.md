# Vedic Bhavas

Source basis:

- Narasimha Rao, Vedic Astrology: An Integrated Approach.

## Definition

Bhavas are houses counted from a reference point.

Default reference point:

- Lagna.

Other possible reference points:

- Chandra Lagna.
- Ravi / Surya Lagna.
- Arudha Lagna.
- Hora Lagna.
- Ghati Lagna.
- Special Lagnas.

## Generator Rule

Every Vedic house interpretation must record the reference point.

Example:

- "7th from Lagna" and "7th from Chandra Lagna" are different interpretive statements.
