# Vedic Grahas

Source basis:

- Narasimha Rao, Vedic Astrology: An Integrated Approach.

## Primary Grahas

| Graha | Common English Name | Type | Notes | Cautions |
|---|---|---|---|---|
| Surya | Sun | Luminary/graha |  | Do not equate automatically with Western Sun. |
| Chandra | Moon | Luminary/graha | Important for mind and nakshatra-based dashas. | Birth time and exact lunar position matter. |
| Mangala | Mars | Graha |  | Avoid simplistic aggression claims. |
| Budha | Mercury | Graha |  |  |
| Guru / Brihaspati | Jupiter | Graha |  | Avoid guaranteed fortune claims. |
| Shukra | Venus | Graha |  | Avoid deterministic relationship claims. |
| Shani | Saturn | Graha |  | Avoid fear-based wording. |
| Rahu | North Node | Chhaya-graha / shadow graha | Mathematical point treated as a graha. | Avoid sensational language. |
| Ketu | South Node | Chhaya-graha / shadow graha | Mathematical point treated as a graha. | Avoid fatalistic karmic claims. |

## Generator Rule

Graha meanings should be interpreted inside Jyotish context and not silently imported from Western astrology.
