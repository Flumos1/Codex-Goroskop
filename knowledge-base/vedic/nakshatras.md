# Vedic Nakshatras

Source basis:

- Narasimha Rao, Vedic Astrology: An Integrated Approach.

## Definition

The zodiac is divided into 27 nakshatras.

- Each nakshatra spans 13°20'.
- Each nakshatra has 4 padas.
- Each pada spans 3°20'.

## Generator Rule

Nakshatras are a separate symbolic layer and should not be collapsed into Western signs or generic rashi meaning.
