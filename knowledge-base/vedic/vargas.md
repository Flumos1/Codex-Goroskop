# Vedic Vargas

Source basis:

- Narasimha Rao, Vedic Astrology: An Integrated Approach.

## Definition

Vargas are divisional charts produced by dividing a rashi into equal parts and mapping each part to another rashi.

Each varga can be treated as a chart and is associated with a life sphere.

## Initial Vargas

| Varga | Name | Division | Initial Use |
|---|---|---:|---|
| D-1 | Rashi | 1 | Base chart. |
| D-2 | Hora | 2 | Resources and wealth topics in later research. |
| D-9 | Navamsha | 9 | Important divisional chart; detailed use to be researched. |
| D-10 | Dashamsha | 10 | Career/work status topics in later research. |
| D-12 | Dwadashamsha | 12 | Family/lineage topics in later research. |
| D-20 | Vimshamsha | 20 | Spiritual practice topics in later research. |

## Generator Rule

If a Vedic report discusses a topic without using the relevant varga, advanced mode should say that only the base chart layer was used.
