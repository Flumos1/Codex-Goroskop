# Natal Synthesis Rules

## Rule 1: Aspects As Inner Statements

Source basis:

- Psychological astrology source family.
- Initial source: Greene / Sasportas, Development of Personality, Vol. 1.
- Practical synthesis support: Kolesnikov, Astrology Self-Study.

When interpreting an aspect, do not begin with an event prediction.

Use this pipeline:

1. Identify each planet's archetypal principle.
2. Identify the aspect's relationship pattern: fusion, tension, polarity, flow, opportunity.
3. Translate the combination into an inner expectation, belief, or life statement.
4. Describe possible perceptions or repeated emotional patterns.
5. Offer a constructive way to live the same archetypal material.

## Rule 2: Parent Symbols Are Inner Images

Moon and Sun can be used for mother/father symbolism, but only with caution.

The project should frame these factors as:

- Inner image.
- Expectation.
- Perceptual filter.
- Psychological template.

The project should not frame them as:

- A factual claim about what the parent did.
- A diagnosis of the parent.
- A fixed childhood event.

## Rule 3: Conflict Means Dialogue

When chart factors conflict, render them as inner parts that need coordination.

Useful structure:

- Part A wants or needs X.
- Part B wants or needs Y.
- The tension is not a defect.
- The task is recognition, acceptance, coordination, and integration.

## Rule 4: Constructive Channel

Every difficult natal factor should include at least one constructive channel.

Template:

- "This can feel like..."
- "At a more conscious level, it can become..."
- "A useful question is..."

## Rule 5: Source Separation

If a rule comes from psychological astrology, mark it as such in advanced mode or internal metadata.

Do not present psychological interpretation as classical doctrine unless a classical source also supports it.

## Rule 6: Topic-Scoped Report

Do not imply that one factor describes the whole person.

Each section should be scoped by life topic:

- Self and first reaction.
- Emotional needs.
- Resources.
- Learning and communication.
- Home and roots.
- Creativity.
- Work and routine.
- Partnership.
- Transformation.
- Worldview.
- Public role.
- Groups and future plans.
- Retreat and hidden service.

## Rule 7: Multi-Factor Synthesis

Single-factor rules are ingredients, not the whole meal.

When multiple rules are selected:

1. Group repeated themes.
2. Separate resources from tensions.
3. Notice angularity and house emphasis.
4. Avoid letting one placement dominate unless the chart strongly repeats it.
5. End with a constructive reflection.

## Rule 8: Forecast Method Humility

When forecasting is added later:

- Name the method.
- State the method's limits.
- Avoid claiming that any one method sees all events.
- Prefer symbolic timing and tendency language.
