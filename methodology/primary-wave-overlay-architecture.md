# Primary Wave And Overlay Architecture

This project can generate reports in two layers:

1. Primary wave: one chosen foundational source or method that carries the main reading.
2. Overlay layers: additional source-backed systems that refine, correct, compare, or add nuance.

## Primary Wave

The primary wave is the main interpretive signal for a report mode.

For the birthday-personology mode, the primary source is:

- Goldschneider - The Secret Language Of Birthdays.

This mode is useful when a user wants to analyze a person, partner, potential partner, friend, family member, or another important figure from one central source without requiring a full natal chart.

## Overlay Layers

Overlay layers can include:

- Western natal astrology.
- Psychological / archetypal astrology.
- Compatibility and relationship architecture.
- Kabbalistic / esoteric sources.
- Vedic / Jyotish, when explicitly requested.
- Chinese / East Asian systems, when source-backed.

Overlay layers must not overwrite the primary wave silently. They should be marked as additions, contrasts, or corrections.

## Report Modes

### Source-Only Mode

Use only the primary source family.

Example:

- "Analyze this person only through Goldschneider's birthday-personology source."

### Stereo Mode

Use one primary wave plus overlay layers.

Example:

- Primary wave: birthday personology.
- Overlay: compatibility relationship type, psychological astrology, and chart factors.

## Safety

The public output must avoid deterministic claims.

Do not turn birthday-personology into:

- guaranteed prophecy;
- relationship verdict;
- fixed personality label;
- fatalistic destiny claim.

Use it as a strong symbolic portrait and then let overlay layers add nuance.
