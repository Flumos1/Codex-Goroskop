## Project Role

This source is useful as a practical Western synthesis and teaching source.

It is especially useful for:

- Explaining chart components in accessible language.
- Building a beginner-friendly report flow.
- Connecting planets, signs, houses, aspects, lunar nodes, and examples.
- Supporting the idea that forecasting methods show partial slices rather than total certainty.

## Core Interpretive Ideas

### 1. Report Language Should Be Teachable

The source is structured as a self-study guide, so it supports a report style that explains terms while interpreting them.

Generator use:

- Simple mode should avoid dense jargon.
- Advanced mode can show the technical factor after the human explanation.
- The report should teach the user how the interpretation was assembled.

### 2. Horoscope Reading Depends On The Question

The profile text states that a horoscope can be read for different aims: character, money, learning, partnership, and other topics.

Project rule:

- The generator should not claim to cover "the whole person" from one factor.
- Report sections should be scoped by topic.

### 3. Synthesis Is Multi-Factor

The source covers planets, signs, houses, aspects, nodes, examples, and weighted assessment patterns.

Generator use:

- Treat single-factor rules as ingredients.
- Build synthesis sections from repeated themes, angularity, house emphasis, and aspect patterns.
- Avoid letting one placement dominate the whole report unless calculation strength clearly supports it.

### 4. Forecasting Methods Are Partial

The profile headings include a cautionary forecasting principle: each method shows its own slice and no method shows all life events.

Project safety rule:

- Forecasting output should identify which method is being used.
- Avoid method inflation: a complex method is not automatically more reliable.
- Use probability and tendency language, not certainty.

## Generator Rules To Add Later

### Rule: Topic-Scoped Report

Each report section should state which life topic it is addressing:

- Self and temperament.
- Resources.
- Learning.
- Home.
- Creativity.
- Work and routine.
- Partnership.
- Transformation.
- Worldview.
- Public role.
- Groups.
- Retreat / hidden service.

### Rule: Multi-Factor Synthesis

When multiple rules are selected:

1. Group by repeated themes.
2. Mark angular or house emphasis.
3. Separate resources from tensions.
4. End with a constructive reflection.

### Rule: Forecast Method Humility

When using forecasting:

- Name the method.
- State that it is one symbolic lens.
- Avoid claiming complete life-event coverage.
