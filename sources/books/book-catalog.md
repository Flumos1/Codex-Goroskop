# Book Catalog

This catalog tracks source intake, sorting, and research priority.

Raw new files first arrive in `sources/books/inbox/`. After triage, approved books are physically moved into `sources/books/library/` by category.

## Status Legend

- `new`: uploaded, not yet reviewed.
- `triaged`: category and role assigned.
- `sampled`: first-pass text/structure review completed.
- `summarized`: research notes created.
- `methodology-ready`: ideas extracted into project methodology.

- `library/99-new-arrivals-review/`: temporary review category for uncertain new sources.

## Intake Rule For New Books

Put all new books into:

`sources/books/inbox/`

Then run the new-arrivals review:

1. Identify title, author, year, language, format, file size.
2. Assign one primary category and optional secondary categories.
3. Assign priority from 1 to 3.
4. Decide whether the source is for foundation, comparison, style, or caution-only review.
5. Add it to this catalog before extracting ideas into methodology.
6. Move the file into the correct `sources/books/library/` category after review.
